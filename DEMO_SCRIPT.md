# Six-hour hackathon demo script

Use only a valid reference that the team is authorized to access. Recheck the public page immediately before presenting; shipment data can change.

## 90-second core demo

1. Open Dashboard. Point out that the counters are based on real saved lookups and are zero until used.
2. Open Track Shipment and choose the first carrier with a verified working integration.
3. Enter the prepared reference and click **Track shipment**.
4. Show the loading state while TinyFish investigates the official carrier page.
5. Explain the retrieved status, latest event, location, and ETA only if actually returned.
6. Open the official source link and verify a key field against the page.
7. Repeat with a second carrier if the first live result succeeded quickly.
8. Open Tracking History to show retrieval timestamps and saved snapshots.
9. If a field is missing or a lookup is restricted, explain it transparently rather than showing fabricated data.

## Optional extras if the core works

- Batch lookup with two to five already-verified references.
- CSV export.
- Demonstrate how an explicit carrier delay/exception status creates a warning.
- Open Carrier Sources to show the official source directory.

## Do not claim

- Support for every carrier unless each integration was tested.
- That a past event timestamp by itself proves a delay.
- Guaranteed real-time physical location.
- Guaranteed avoidance of demurrage or financial savings.
- CAPTCHA bypass, automatic rebooking, or automatic shipment modification.
